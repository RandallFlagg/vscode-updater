# Agent Definitions

This project uses specialized AI agents defined in the [AGENTS/](./AGENTS/) folder.

| Agent | File | Role |
|-------|------|------|
| Coder | [AGENTS/CODER.md](./AGENTS/CODER.md) | Autonomous Senior Software Systems Architect — design, refactor, implement, debug |
| Reviewer | [AGENTS/REVIEW.md](./AGENTS/REVIEW.md) | Read-only code reviewer — identify flaws, destructive ops, resource hazards |
| QA | [AGENTS/QA.md](./AGENTS/QA.md) | Read-only QA tester — cross-reference docs vs implementation, verify parity |
